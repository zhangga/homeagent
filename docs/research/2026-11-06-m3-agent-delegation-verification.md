# M3 专业 Agent 委派与子事项协作验收记录

日期：2026-11-06。范围：用户授权的 M3；M4 可选 DeepSeek Harness 接入不在本轮范围内。

## 实现与存储

- 群仍绑定一个协调 Agent。计划中的步骤可以选用管理页已发布的专业 Agent，固定发布版本；后续修改、重启与重试不能偷偷替换版本。每个 write/full Task Run 继续单独审批，每个成果继续使用原有验收规则。
- 明确要求独立推进的工作形成同 Space 子事项，独立分支使用现有并发额度；同一子事项内部顺序执行。父步骤仅在依赖事项完成、成果已验收且没有待处理补充时继续。
- 汇总输入只包含每个依赖的最后一份已验收报告及其 Action/Run/Raw 引用。未验收成果保持 held，不进入知识提炼；最终完成通知只登记父目标并回复原话题。
- 暂停父目标阻止子事项后续领取；取消先保存所属子事项的取消意图，再通过原有接口取消，恢复时补齐。不会取消独立事项或仅被引用的其他事项。
- WorkItems v4 兼容 v1–v3，工作计划 v3 兼容 v1–v2，遇阻事件 v2 兼容 v1，Space archive v24 兼容 v1–v23。归档不携带本机执行授权、取消队列、投递来源或 Provider 会话。
- 工作台展示父子关系、依赖验收状态、每步 Agent 及版本；原话题补充可路由到明确指定的子事项，单个子事项等待事实时可直接回复所缺信息。
