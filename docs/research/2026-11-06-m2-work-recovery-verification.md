## 实现与存储

- 开启续作的聊天事项，成功结束的 Task Run 报告业务阻塞或成果被人工驳回后，持久登记一次无工具重规划。原目标内有替代路径则修订剩余步骤；缺少必要资料或决定则提一个具体问题并等待。
- 冻结触发 Action/attempt/Run、计划快照、报告、Agent revision 和规划配置。同一事实不循环规划；Provider 失败、中断或原样返回失败步骤不能被伪装成自动重试。
- 新计划保留已验收成果，替代动作继续逐次审批、执行和验收。修订回执送达才放行续作；暂停、关闭续作、来源撤回和过期决策继续生效。
- 计划定义 v2 兼容 v1；WorkItems v3、WorkContinuation v2、WorkDispatch v1 保持原格式。`config/work-events/` 保存本机事件及通知 v1，Space archive v23 仅携带计划与触发动作历史，兼容 v1–v22。
- 最终验收前登记完成 watch，验收和事项完成后形成持久通知。使用事项、计划版本、类别组成幂等身份，沿用 Task 通知退避间隔；本地回执保存失败保留已知远端 receipt，重启不重跑工作。
