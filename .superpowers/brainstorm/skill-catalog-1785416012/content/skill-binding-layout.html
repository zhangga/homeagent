B. 独立管理抽屉

目录信息更完整，也更容易扩展来源和更新管理；但第一版操作更重，并提前引入接近独立 Skills 页的结构。

本阶段建议

  • 优先选择 A，保持最小闭环。
  • 选择器仍展示 Skill 来源路径和 Provider 可用性。
  • 未来增加 Git/URL 导入时，再自然升级为独立管理页。

共同约束

  • Agent 只保存稳定 Skill 标识，不复制 SKILL.md 内容。
  • 运行前重新解析可用性。
  • 不可用 Skill 按你选择的策略跳过并警告。
