稳定来源标识
SkillCatalog

扫描本机目录、解析 SKILL.md、合并相同内容、标记冲突与 Provider 可用性。

Execution Resolver

每次调用按 Agent 绑定解析实际可加载 Skills，并遵守对话或任务权限。

Run Evidence

记录 loaded / skipped / warning；任务写入运行历史，对话把警告附在回复末尾。

边界约定

  • AgentStore 只保存绑定关系，不保存或复制 SKILL.md 内容。
  • SkillCatalog 是只读目录投影，首版不引入 skills.json、文件监听或远程同步。
  • 空间换绑 Agent 后，新请求立即使用新 Agent；历史任务继续保留启动时快照。
  • 个人空间沿用同一模型：个人空间 → Personal Agent → 该 Agent 的 Skills。
